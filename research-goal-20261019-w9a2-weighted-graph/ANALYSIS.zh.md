# W9A2 固定 24 叶图的加权平均能量候选

范围：只有一次固定有限图的整数/有理数算术。输入是既有
`geometry-audit.json` 的 48 个坏顶点和 37 条边，未修改原图、原证据或
已冻结的 `w9a2-structural-routes` 目录。没有 LP、核函数求值、Lean、
新增 cell、阈值搜索或全高记忆图。

## 结果

不加权的“所有坏窗都用同一个最小 floor”会把图中的环视为阻碍；
保留各叶原有 margin 后，这个环必须穿过代价较高的叶。
固定图的最小平均代价精确为

\[
\mu=\frac{622387738726}{5}
\]

（单位为 `CN`，即能量乘 `10^20`）。因此得到有限图平均 floor 增量

\[
\Delta c=\frac{311193869363}{250000000000000000000}
        =1.244775477452\times10^{-9}.
\]

这比首七叶 DAG 的增量 `2.42781187048·10^-10` 大约 5.12715 倍。
其数学作用是控制共享窗口序列的长期加权平均，并没有提高每个单独窗口
的最小值。**完整 actual localization 和计数形式化仍未完成**。

## 固定图及可独立核验的证书

坏顶点 `v=0,...,47` 编码为 `2*zero_based_leaf_rank+reversed`。
其代价取原叶 margin 的安全整数下界

```
cost[v] = floor(margin[rank] / 335544320000000000).
```

加一个好顶点 G=48，代价 `10^12`，即 floor 增量 `10^-8`。
原审计已经统计恰好 24 叶低于此阈值，因此其余 11770 数字叶可归入 G。
所有 `G→bad`、`bad→G`、`G→G` 均保留，得到 49 点、134 边的保守外图。
每条边的代价为源顶点代价。

一次精确 Karp 动态规划只用于发现 μ。交付的真正证书是分母为 5 的有限
有理势 p，以及对**全部 134 条边**逐一验证的

\[
\operatorname{cost}(u)\ge\mu+p(v)-p(u)\qquad(u\to v).
\]

再交付一个平均值等于 μ 的 tight 环，便同时证明固定外图的下界和最优性。
后两项都可以只用有理数代入核验，不必信任 Karp 算法实现。

达到 μ 的环为

```
10 → 14 → 11 → 19 → 18 → 10
```

对应源代价为

```
13734031, 121390593524, 13734031, 250484838570, 250484838570.
```

总和为 `622387738726`，共五条边，全部 potential slack 为零。
该环只是外图的最优环，**不是实际低能周期 gap 配置**。此前同一环一轮
六窗 word 在原几何下可行，也没有证明它能无限重复或具有这些实际能量。

证书中 `p(G)=0`，`0≤p≤500944400138`（CN 单位）。任意有限 N 窗
label 序列末端总可以接一条到 G 的图边，对全部 N 条源代价求和即得

\[
\sum_{t=0}^{N-1}F_t\ge
 N\left(c_0+\frac{\mu}{10^{20}}\right)
 -\frac{500944400138}{10^{20}}.
\]

势差只产生固定边界损失 `5.00944400138·10^-9`；它不随窗数累计。
但每个实际窗口的标签存在性、反射处理、相邻边的实际覆盖及传到原
matching/band/counting 的过程，均还需要 Lean 中的完整证明。

## 分离域根外补偿的静态检查

新源的

```
B = 454741897490 / 10^14,
max b_r = 79272929552 / 10^14.
```

在分离 remainder 中，每个 gap 均至少 `17/20`。原 cover 的一个 gap
若已通过原 WZ 或大 gap tail 付出 `c0`，其余七个 gap 的线性压力仍在
实际 `Fw` 内，并且至少再付

\[
\frac{17}{20}(B-\max b_r)
=\frac{3191486227473}{10^{15}}
=0.003191486227473>10^{-8}.
\]

因此沿用原单-gap `c0` 证书已足以把这些根外分离窗口归入 G；不必
重新评价原 WZ 得到更强核下界。原小 gap≤1/2 分支与分离≥17/20冲突。
此处是基于原 source 单-gap 定理的静态推导，未声称重放了所有 WZ
数值或完成了升级后的 actual 全覆盖 Lean 定理。
