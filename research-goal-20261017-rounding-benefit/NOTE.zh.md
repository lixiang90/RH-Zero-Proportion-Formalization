# 公共取整：全整数 floor 与一个固定收益检查

2026-10-17，宏观回顾 002 后第 2 主轮。此包只对已存的实际整数
jet 区间做精确有理算术，不产生新整数中心或超越函数数据，不调用
优化器，不枚举九维配置，不编译 Lean。没有得到无条件零点比例。

## 相邻项足够给出全正整数配置的下界

令 h 的九个 gap 都是正整数。原核 w 是平方，全部配对系数非负，故

    F(h) >= sum_r (b_r*h_r + a_(r,r+1)*w(h_r)).

对于每个 r，检查 n=1..32 的现有 w(n) 区间下端，并把 n>=33 的
所有整数一起用 b_r*n>=33*b_r 处理。九个一元最小值都在 n=2。
因此在已有实际区间语义下，整个正整数九 gap 域有下界

    L_adj = 49010784449364406850369272140464640617 /
            5000000000000000000000000000000000000000
          ≈ 0.009802156889872881.

这超过 .0088 和 .00884；不需要把每个整数配置塞进既有 69 个盆地。
这里给出有限算术及纸面推导，**尚未新增全整数配置 Lean 定理**。
旧 JSON 的历史 `global_floor_proven=false` 没有被修改或当作当前证据；
实际数据语义须用当前整数中心定理核对。该下界不能直接用于连续 gap。

## 为什么必要条件仍然不够

公共舍入恒等式对任意原域配置为

    F(g) = avg F(q) - (5/128)*B + Phi(g).

若要用相互独立的常数界完成转移，仍须另证整个原域 Phi(g)>=m，
才能得到 F(g)>=L-(5/128)*B+m。全局极小点比较给出的却是 Phi 上界。
现在全整数 floor 已在纸面超过 c，任意 F(g)<c 都自动小于所有整数
竞争点；因此仅增加“极小点不大于舍入配置”的消费者不能排除它。

## 固定的两点反证尝试没有通过

在计算前声明 q* 的九 gap 全为 2，g* 的九 gap 全为 21/20。
如果 L 是含 q* 的全整数域下界，m 是含 g* 的整个原域 Phi 下界，则

    L - (5/128)*B + m <= F(q*) - (5/128)*B + Phi(g*).

对右侧做严格上界，若小于 .0088，就能排除所有这种解耦常数法。
本固定检查得到 F(q*)≈.00982472114029，Phi(g*)≈+.006349408935，
右端上界≈.01600138521605，**没有通过反证门槛**。receipt 的
`decoupled_L_and_m_cannot_reach_0088` 明确为 false；不能据此宣称
解耦方法不可能，也不能据这个偏大的上界宣称方法有效。

所有连续值只用原来 23 阶 Taylor 系数，余项为
(44/7)^24*|x|^24/24!。已有 `WindowTaylorBridge.w24_twentyfour_abs_le`
是其实际导数依据。正权边 z=21*(j-i)/20 最近整数偏移至多 .45；
插值参数为 697*(j-i)/640，端点严格为 j-i、j-i+1。
Phi 上界正确使用实际 w 的上端减插值下端。

固定算术重复只用于补齐表 hash pin，未改变配置、核、参数、精度、
目标或算法。没有根据该失败点继续扫新的配置。独立常数、条件于极小
点的下界、带额外域条件的界以及耦合转移是不同问题，不能混同。
