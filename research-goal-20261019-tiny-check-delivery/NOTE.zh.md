# sync42 冻结文件交付范围

本包仅整理既有冻结文件，逐项核对内部清单的字节数和 SHA256。未执行任何研究 producer、模型导入、数学计算、编译、导出、内核重放或网络操作；旧文件未改。

收录 v3 实际生成的 Solution、v0 生产准备及授权门、失败/未完成冷验证的冻结小日志、Nanoda 诊断脚本、官方 native verifier 源码快照、去重静态审阅与等价生产源、独立文本审阅、v4 flatten 准备、尚未执行的 production v1 准备、旧 materials 准备，以及 native-tools v0/v1 的静态准备和用户审阅材料。v4/production v1/materials 的准备清单不代表执行成功；native-tools v0/v1 的清单也不代表工具构建通过。

运行中的或随后产生的 setup 收据不在本包。外部 SDK、runtime 二进制、olean、NDJSON 和 archive 不进入 flat files；原始 tmp 路径只作内部 pin 核对，相关生产小日志使用 research-goal 目录下已冻结副本。外部 574 MB SDK 仅保留原身份元数据，本次未重新读取。

本包不增加证明结论。完整冷路径 3200 秒通过、Nanoda 全部目标通过及官网接受仍未由这些材料证明。submission 目录是可审阅草稿，网站当前状态未确认，不能视为已提交或已接受。

清单以 write-new 方式生成，files.json 不自引用。其自身 SHA256 另向父任务报告。
