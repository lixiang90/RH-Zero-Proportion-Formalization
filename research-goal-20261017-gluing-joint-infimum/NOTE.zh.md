# 保存的九点正组合不存在联合不兼容增益

这是第 3 主研究轮的独立静态备选审查。它只分析已保存的精确组合，
不重开系数优化、不评价实际核、不读取覆盖树、不调用 Lean。

`research-goal-20261017-ninepoint-decomposition/coefficient-gluing.json`
的精确原始向量只有两个正系数：

- 删除顶点 0：`lambda0 = 6666666576972640000000000 / 6666666732353512328627341`；
- 删除顶点 1：`lambda1 = 538164163700000000 / 20000000197060536985882023`。

其余八项严格为零。第二项约为 `2.690820792e-8`，但下述结论并不
依赖它很小；对这两个嵌入的任意非负系数且总和正都成立。

## 全域恒等与严格的适用范围

令 `F9(h)` 为旧十二模核、旧九点权重的实际能量，`h` 是八个非负
间隔；令十点的九个间隔为 `g0,...,g8`。两个删除嵌入给出

`h0(g) = (g1,g2,...,g8)`，

`h1(g) = (g0+g1,g2,...,g8)`。

因此其组合是

`F_lambda(g) = lambda0 F9(h0(g)) + lambda1 F9(h1(g))`。

关键事实是：对任意旧九点间隔 `h=(h0,...,h7)>=0`，选择规范提升

`g = (0,h0,h1,...,h7)`，

就有 `h0(g)=h1(g)=h`，从而

`F_lambda(g) = S F9(h)`，其中 `S=lambda0+lambda1>0`。

对任意实数 `L`，因此有精确的全域下界等价：

`(forall g>=0, F_lambda(g)>=L)`

`iff (forall h>=0, F9(h)>=L/S)`。

右向左使用两个非负系数相加；左向右只需代入规范提升并除以正数
`S`。这比猜测旧极小点的具体模式更强：**所有旧九点模式、所有
旧极小化序列都可以在这两个嵌入中同时实现**，没有模式不兼容性。
若记旧实际全域下确界为 `m9`，则严格得到

`inf_(g>=0) F_lambda(g) = S m9`。

`audit.py` 检查两个八乘九的间隔拉回矩阵，与规范提升的九乘八矩阵
复合都恰为单位矩阵。检查全部使用标准库整数和有理数。

这里使用的确是原证明的域：`GramDefect20261015/Core.lean` 的
`RiemannFail.cert_AM` 明确量化 `g : Fin 8 -> Real`、`forall i, 0<=g i`，
没有正分离前提。原下界证明并未把零间隔排除。

即使另一个应用仅允许所有十点间隔严格正，上述组合的下确界仍相同。
对任意非负 `h`，先取 `h+epsilon`（逐坐标相加），再令 `g0=epsilon`
并作相应提升；当正 `epsilon` 趋于零，两个拉回都趋于 `h`。旧实际
能量由线性压力和有限个连续实际核项组成，故能量趋于 `S F9(h)`。
严格正域的下界方向仍由每个旧能量不小于 `m9` 给出。此连续性说明
没有实现成新 Lean 定理。

## 达到任务幅度所需的确切旧下界

保存的总压力记为 `B`，冻结窗下界为 `H`，任务目标为
`K=R+1/100000`。若组合使用一个全域能量下界 `L<1`，比例
`(H-B)/(1-L)>K` 等价于

`L > (K-H+B)/K`。

对已保存的精确向量，右边约为 `0.008610231606425458`。
除以 `S`，等价要求旧九点统一下界严格大于

`0.008610231575419349`。

现已证的旧下界为

`c9=859538525913875481/10^20 = 0.00859538525913875481`。

所以仍需旧九点全域 floor 提升严格超过约
`0.000014846316280593432`。全部精确分数保存在 `exact-replay.json`。
这不能通过此二项组合的联合不兼容性补偿：若得到所需组合下界，
规范提升立刻给出同等强度的旧九点全域下界。

此结论**没有**断言旧实际下确界 `m9` 等于已证 `c9`，也没有排除
独立改进旧九点定理的可能性。它准确排除的是“现有两个正嵌入不能
同时达到旧最坏模式，所以能免费增加联合 floor”这一理由。

结论也不覆盖其他系数支撑，例如删除 0 和 9 的组合。那些组合的
联合极小值可能不同；当前未对其做优化、分类或新全域数学证明。
因此本包的停止决定仅是：不为已保存支撑 `{0,1}` 启动联合不兼容
补偿实现，保留原主线的压力耦合损失预算研究。

本包没有新无条件比例、新 Lean floor、完整分类或网站可提交文件。
