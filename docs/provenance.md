# Provenance

The mathematical result and exact data originate in RH-Weil, research round502,
based on commit `609fe754aa6e9b22142f9539ddc28107145442f3`.
The copied Python files, JSON and original structural bridges are byte-preserved
inputs. Their existing canonical-LF dependency pins remain checkable.
The paper build manifest refers to the original RH-Weil checkout and its ignored
scratch evidence; those scratch files are not implied to be present here.

The AM window and PC8 tables derive from the Apache-2.0 proof submitted at
`josusanmartin/riemann@d272437e7ebeb17b87c8c3d7cece592aa23785ab`.
The lossless separation mechanism was studied from arXiv:2610.08965v1.
The newly proved Lean helpers and all later formalization are maintained here.
Upstream copyright notices are preserved. The repository uses Apache-2.0,
consistent with the website's accepted proof license.
