# 固定六阶单元的全域相关性审计

固定单元 `r001000001000100110011001` 已在旧数值覆盖的历史基线中
以 4 个分支、5 个 accepted 叶闭合，叶记录位置为 23790–23794。
它与当前 17 个 frontier 路径均无前缀关系，新增 journal 也没有该
单元或其后代。因此，新六阶证书没有关闭任何当前待处理区域。

本审计只读打开目标为 `11/1250` 的 SQLite 数据库，前后完整 SHA256
均为 `ceb41e0e34b79e92bff8bf658b91510be8c6bc2da4fe527d5bbc1200f5866296`，
与已冻结的 progress 记录一致。导出全部 17 条本单元相关记录及
17 个 frontier 的完整规范 JSON 和摘要，检查完整二叉前缀树及
Kraft 和为 1。独立脚本再次只读核对数据库与导出内容。

五叶的 JSON payload 合计 6,021 字节，加分支与本单元收缩记录共
67,111 字节。这不是一份完整自足 Lean 源码大小：它仍依赖祖先、
实际标量表及消费者。固定六阶证书也没有展示替代这棵小子树的
源码收益。不能把局部模型的不可行性当作完整根覆盖的推进。

`global-relevance.json` 的祖先记录计数用于识别后续研究对象；独立
审计只核验本单元记录、完整前缀树、当前 frontier 和 journal，不
声称已重复验证全部祖先统计。

没有重放历史 132,000 节点的数学不等式，没有证明这些数值记录在
Lean 中成立，也没有证明全域能量下界。大数据库保留本地；公开包
包含可检查的导出、只读查询源和完整数据库摘要。

本证据触发宏观回顾 002。停止扩展这个已闭合小单元；新研究对象
必须说明它能关闭哪些当前未决区域，或能替代多大的已有子树，并
在开启大型求解或编译前给出全域证明与源码收益的验收关。
