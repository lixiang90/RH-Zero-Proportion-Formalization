The actual-function inputs used here are explicit:

(i) the frozen common-anchor F0 interval contains actual F(p_g);
(ii) the old integer Taylor coefficient intervals enclose the Taylor
     coefficients of the actual new-window w' at integers 0,...,32;
(iii) w is C^24 and |w^(24)| <= (44/7)^24 on the required spans;
(iv) the old midpoint polynomial L2 is <= actual F on the whole parent cell.

These analytic inputs are not newly proved in Lean by this package.  The

The derivative bound (iii) has the following analytic justification for
the actual normalized window definition: its nonnegative Fourier profile
on [-1/2,1/2] defines a probability measure, its real characteristic

measure supported on [-1,1].  Differentiating under that compact integral
gives |w^(24)| <= (2*pi)^24 < (44/7)^24.  The frozen cosine coefficient sum
is checked to be <2/25; even with a factor 2 in the cosine convention the
profile is bounded below by 1-4/25>0.  Connecting the actual definitions,
coefficient enclosures and differentiability to the Lean kernel remains
an explicit analytic obligation, not a consequence of Python arithmetic.

2. Dynamic Taylor polynomials and exact error payments
------------------------------------------------------
For each edge let p=s_e(p_g), d=s_e(g)-p, |d|<=R on the whole parent span,
and let |w^(j)(p)-mu_j|<=eps_j for j=1,...,4.  Let M5 bound |w^(5)| on the
whole parent span, as derived from the old table above.  Taylor's theorem
then gives

 U3(d) = mu_1 + mu_2*d + mu_3*d^2/2 + mu_4*d^3/6,
 |w'(p+d)-U3(d)| <= E(d),
 E(d) = eps_1+eps_2*R
        +(eps_3/2+eps_4*R/6)*d^2 + M5*d^4/24.

Indeed |d|<=R and |d|^3<=R*d^2 pay the odd anchor errors.  The remainder
retains the actual nonnegative quartic d^4, not the constant R^4.  For the
energy increment the valid lower polynomial is

 J4(d) = sum_(j=1..4) mu_j*d^j/j!
         -eps_1*R -(eps_2/2+eps_3*R/6)*d^2
         -(eps_4/24+M5*R/120)*d^4.

Here the fifth-order energy remainder is <=M5*|d|^5/120
<=M5*R*d^4/120.  All anchor derivative errors, including first-order
constant payments, are retained.  With the same common aggregate F0lower,

 L4(g)=F0lower+P(g)-P(p_g)+sum_e a_e J4_e(d_e) <= F(g).

For a free coordinate define
 H_r=b_r+sum_(e contains r) a_e U3_e,
 Err_r=sum_(e contains r) a_e E_e.
At actual KKT, |H_r|<=Err_r.  Since |y_s|<=1, also |y_s H_r|<=Err_r.
Thus Err_r +/- H_r and Err_r +/- y_s H_r are nonnegative polynomials.
There are 9*(1+9)*2=180 scalar rows.  The right side remains Err_r;
there is no invalid degree-five multiplication of the error polynomial.
