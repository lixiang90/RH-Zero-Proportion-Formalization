## 2. 一个精确恒等式：a 的同距离位置重分配是有界势差

固定同一个函数 w、同一 b。取两个九点 ledger W、W'，并假定对每个
`s = 1,...,8` 有相同的距离质量

\[
A_s=\sum_{i=0}^{8-s}a_{i,i+s}
   =\sum_{i=0}^{8-s}a'_{i,i+s}.
\]

记 `d_i^s = a_{i,i+s} - a'_{i,i+s}`，
`C_i^s = Σ_{j=0}^i d_j^s`。质量相等意味着 `Σ_i d_i^s = 0`。
在七 gap 状态 `h = (h0,...,h6)` 上定义

\[
U(h)=\sum_{s=1}^7\sum_{i=0}^{7-s}C_i^s\,
w(h_i+\cdots+h_{i+s-1}).
\]

则对每个实数八 gap 窗口 g 都有**恒等式**

\[
F_W(g)-F_{W'}(g)
=U(g_0,\ldots,g_6)-U(g_1,\ldots,g_7). \tag{1}
\]

证明按每个 s 比较同一物理 span 的系数：第一个系数是 `C_0^s=d_0^s`，
内部系数是 `C_i^s-C_{i-1}^s=d_i^s`，最后一个系数是
`-C_{7-s}^s=d_{8-s}^s`。`s=8` 只有一个 a，质量相等使差为零。
b 完全相同，因此其项抵消。这个推导不要求 gap 非负或分离。

新源码 3468 行 `wfun x = kfun x ^ 2`，3573 行给非负性，3575 行
`abs_kfun_le_one` 给 `|kfun x| ≤ 1`，因此 `0 ≤ w(x) ≤ 1`。
故 U 有界；例如 `|U| ≤ Σ_s Σ_i |C_i^s|`。对任意长 gap 序列求和，
等式 (1) 的内部项全部抵消，只剩首末状态的势差。因此 **固定 b、kernel
和 A_s 后，调整 a 在同一距离内的位置分配不会改变无限序列的平均能量**。

对任意有限周期 gap 序列，首末状态相同，甚至严格有

\[
\frac1L\sum_{t=0}^{L-1}F_W(g_t,\ldots,g_{t+7})
=B\,\overline g+
\sum_{s=1}^8 A_s\frac1L\sum_{t=0}^{L-1}
w(g_t+\cdots+g_{t+s-1}). \tag{2}
\]

式 (2) 的 gap 索引都取模 L；因此周期平均对 b 的位置分配也只依赖 B。
**这不意味着一般有限非周期序列中的 b 重分配是有界势差**：gap 未设上界时，
相应线性势函数可能无界，不能直接把它并入固定边界损失。

### W9A2 的确切距离质量

对 10626 行 TS 的 34 个非零项作有理数求和得到

| 距离 s | A_s |
| --- | --- |
| 1, 3, 4, 5, 6, 7 | 2 |
| 2 | 199999999999999 / 10^14 = 2 - 10^-14 |
| 8 | 99999818328269 / (5·10^13) = 2 - 0.00000363343462 |

特别地，新 refit 的大多数 a 自由度只是这种位置分配。设 W' 把每个
A_s 全放在 `(0,s)`，并保留原 b，则
`C_i^s = -Σ_{j=i+1}^{8-s} a_{j,j+s} ≤ 0`。
由 `0 ≤ w ≤ 1` 可取

\[
-C\le U\le0,\qquad
C=\sum_{s=1}^7\sum_{j=1}^{8-s}j a_{j,j+s}
=\frac{2799999999999997}{10^{14}}=27.99999999999997.
\]

此 C 较粗但固定，与窗数无关。源码 a 的反转对称性也逐有理数核对，
所以另有 `C = Σ_s (8-s) A_s / 2`。这里只说明确切的平均能量等价，
并不主张将此粗边界直接加入最终源码更有效率。

### 对研究方向的含义

refit a 的单窗优化，等价于在一个**受限的线性 span 势函数族**中重新分配
各窗的能量。它可能改善单窗最小值，但相同 A_s 的周期平均结构不变。
因此更有希望的拓展是允许分段/非线性势函数，或用真实共享 span 的多窗
约束控制平均能量；这扩展了 refit 可表达的证书族，是否有严格数值增益
仍须经过下面的机会 gate。它与旧势函数尝试
属于同一总体思想，不能仅因换名就称为突破；下节说明旧失败和新机会的区别。

## 3. 可形式化的平均能量定理及严格增益机制

令 `S_t=(g_t,...,g_{t+6})`，`E_t=F_W(g_t,...,g_{t+7})`。
若存在有界函数 V 和 `c > c0`，使对所有分离窗口 `g_r ≥ 17/20` 有

\[
E_t\ge c+V(S_t)-V(S_{t+1}), \tag{3}
\]

那么对每个 N 有

\[
\sum_{t=0}^{N-1}E_t\ge Nc-\operatorname{osc}(V). \tag{4}
\]

证明只是把 (3) 求和。固定边界损失在实际零点计数中随高度消失；仍须
沿用 actual kernel、matching、separated spectrum、band 和计数桥，
不能把 (4) 单独当成无条件 ζ 定理。近点 pair 付款仍要求 `c ≤ 1/64`。

单窗下界是 V=0 的特例；(1) 表明重新分配 a 只涵盖特定线性 V。
分段 V 或联合能量可以把“某窗很低时下一窗必须高”变为 (3)，
即使 `inf E_t` 本身没有提高也能提高平均值。

一个无需猜测精确极小点的量化版本是：已有 `E_t ≥ c0`，若所有满足
`E_t < c0+η` 的八 gap 低能窗口都不能相邻粘合，则
`E_t+E_{t+1} ≥ 2c0+η`，从而平均下界为 `c0+η/2`，仅付固定边界损失。
这是我们旧 singleton overlap 的机制；新 W9A2 必须重新证明完整低能集合
及四个独立反射朝向的粘合不可能，旧 cell 的坐标不适用。

更一般地，有限状态图每条实际转移 e 带经实际函数证明的下界 l_e；
若对每条边 `u→v` 有有理势 `p` 满足
`l_e ≥ c+p(u)-p(v)`，则得到 (4)。有限图最小平均环 ≥c 与存在这种 p
等价，可给短的整数/有理数证书。图可以允许外近似转移，只要覆盖每个实际
连续窗口；过粗图会失去增益。

## 4. 旧负环确实挡住了旧外模型，不能重说成新进展

旧 s1R 的 Mi margin 图和 J 增强图均已有独立核验的负环；只在同图上

### 最小的新机会 gate：先粘合一条新负环的完整 word，再考虑高记忆

1. 只读取新 W9A2 冻结 walk，提取原 lower/margin 和低能 cell 的精确
   gap/span 上下界，不重跑旧 s1R 的数百万 case。
2. 对新图第一条拟阻断目标的 L 边负环 `v0,...,vL=v0`，只建立该**完整
   word** 的自由物理 gap 路径 `x_0,...,x_(L+7)`：第 t 个八 gap 窗口
   为 `x_t,...,x_(t+7)`，同时满足 cell `vt` 的原 gap/span 约束；保留
   每个独立反射朝向。**不能添加 `x_(r+L)=x_r`**：回到同一个 cell 标签
   不意味着回到同一个 gap 数值，强行添加周期等式可能产生虚假排除。
3. 若完整 word 为空，产出原行的严格 Farkas 证书；这只禁止该 word，
   不自动删除它的各条边。按所需长度提升记忆；最小长度三窗失败可把状态

4. 若该自由路径可行，这既不说明能无限重复该 word，也不构成低能反例。
   另外可考虑严格周期 gap 的可行性，但周期几何为空不能禁止上述自由路径。
   只有给出一个实际周期 gap 列，并将 actual kernel 上界严格算到
   “周期平均 ≤目标”，才足以否定该固定 kernel/A_s 的所有势函数路线。
   几何可行和低于目标的线性外模型都不足以作此否决。

### 一个固定非空 edge 的真实共享曲率 gate

对一条新 W9A2 真正几何非空而单窗界欠额的 edge，保持其原锚点/原 hull，
先合并两窗的同一个物理 span。对原有效支持线与同核有效曲率余量

\[
w(s_q)\ge\alpha_q+\beta_q s_q+\gamma_q(s_q-t_q)^2,
\quad\gamma_q\ge0,
\]

用冻结非负乘子形成 `Q(x)=Σ_q λ_q γ_q(v_q·x-t_q)^2`；v_q 是同一十点
位置上的物理 span incidence。原线性模型下界若欠额 d，就检查

\[
\inf_x Q(x)>d. \tag{5}
\]

固定一个平移自由度，精确解至多九维驻点系统，并逐行核对全部 guard、
非负权和恒等式即可给 (5) 的有理证书；奇异时须处理零空间，不得直接求逆。
联合最小值利用整个 incidence 网络的不兼容，可能严格超过逐 span
独立最小值之和。旧 s1R 在固定 Below pair 已证实这种机制确有额外付款，
但那一个点不是新核、不是全域，也不能复用其数值曲率。

停止条件：固定 edge 的 actual guard 不成立、联合曲率付款不足、或严格
actual 周期上界挡住目标时，记录确切范围后停止相应模型；不自动加锚点、
细分、大 LP 或 Lean 批次。固定 edge 成功也只过机会门，不是全域平均界。

结合本轮完整 word 仍可行的实证，进一步争取较大增益时应优先考虑
**W9A2 自身的共享 incidence 曲率付款**，其次才是有明确新排除证据的
高记忆几何；继续反复扩大同一纯几何图暂缺正证据。本轮在此冻结，
上述曲率 gate 没有执行。

## 5. 量级：先对平均 floor 设目标，再谈零点比例

固定新 H 和 B，`κ=(H-B)/(1-c)`。若平均下界提高 Δc，则

\[
\Delta\kappa=\frac{\kappa\,\Delta c}{1-c-\Delta c},
\qquad
\Delta c=\frac{(1-c)\Delta\kappa}{\kappa+\Delta\kappa}.
\]

以官网精确 κ、c0 作有理数算术：比例增加 `10^-6`（百分数增加
`0.0001` 个百分点）需要平均 floor 增约 `1.4713189642·10^-6`；
增加 `10^-5`（`0.001` 个百分点）需要约 `1.4712993059·10^-5`。
这只是目标准换，不是新下界。

结论：值得主攻的数学对象应从 `max_W min_g F_W(g)` 转向“同一实际
gap 序列的最小长期平均能量”，并将非线性势/高记忆兼容/共享 incidence
曲率作为有限证书。此次最具体的新认识是等式 (1)：它解释了普通 refit
已经做了什么，也明确指出要取得超出 refit 的结构增益必须增加什么。
