# W10 的有理 Gram 二次下界：已核查的局部证据与全域缺口

本目录研究一个不同于收紧常数的结构性方法：先将同一组九个间距产生的
39 个核值放进同一个凸二次型，再用显式平方和统一控制它们。下述通用
实数论证是严格的；具体数据已经由两条独立 Python 算术实现进行有理数
核查。**这仍不是 Lean 证明，也没有证明这些格室覆盖全部合法间距。**

候选参数保持原样，SHA256 为
`ad117819d63588c55d89bd59ae7f0ad11072faaf33ffc53bf08d7eef54010e03`。
目标是原来的 `433/50000`，没有修改压力、权重或分数。

## 1. 无需新的导数估计

冻结的 PT 表已经给出带不确定导数的切线。设表内某点为 `p`，点值下界
为 `v`，真实导数 `D` 满足 `s ≤ D ≤ s+e`，且其原证书在区间内证明

\[
v+D(t-p)\leq w(t).
\]

若 `t ≥ L`，则

\[
\ell(t)=v+s(t-p)-e\max(p-L,0)\leq w(t).
\]

证明只需按 `t ≥ p` 与 `t ≤ p` 分类，分别使用导数区间的下端和上端。
这里的坐标应除以 `SC=32768`，点值除以 `10^10`，导数除以 `10^9`。
生成器和独立重放器都保留了这个误差付款项。

设有理区间 `I=[L,U]` 被有理子区间 `[l_j,r_j]` 无缝覆盖。每个子区间
选择一条冻结 PT 已证明有效的仿射下界 `ell_j`。不要求这些线一定构成
最大上包络；只要求选用的每条线确实在相应子区间有效。

对凸二次多项式 `q(t)=alpha*t^2+beta*t+gamma`，`alpha ≥ 0`，若

\[
q(l_j)\leq\ell_j(l_j),\qquad q(r_j)\leq\ell_j(r_j),
\]

那么 `q(t) ≤ ell_j(t) ≤ w(t)` 在整个子区间成立。一个完全代数的证明
使用下列恒等式（`l < r`）：

\[
\begin{aligned}
(r-l)(q(t)-\ell(t))={}&(r-t)(q(l)-\ell(l))
 +(t-l)(q(r)-\ell(r))\\
&-\alpha(t-l)(r-t)(r-l).
\end{aligned}
\]

右边三项均非正。端点重合的情形直接处理。因此具体二次下界可以只用
有限有理数不等式验证，完全不依赖探索阶段采样的 `w''`。

## 2. 所有项共享同一个九维平方和

对边 `i<j`，令 `v_ij` 为九维 `0/1` 向量，在 `i,...,j-1` 处取 `1`。
间距向量为 `g`，跨度就是 `v_ij^T g`。给定有理锚点 `g0`，以及每条边
已经由上一步核查的

\[
q_{ij}(t)=\alpha_{ij}(t-v_{ij}^Tg_0)^2+s_{ij}t+d_{ij}-\epsilon_{ij},
\]

定义

\[
A=\sum_{i<j}a_{ij}\alpha_{ij}v_{ij}v_{ij}^T,
\quad b'=b+\sum_{i<j}a_{ij}s_{ij}v_{ij},
\]

\[
C=b^Tg_0+\sum_{i<j}a_{ij}
   (s_{ij}v_{ij}^Tg_0+d_{ij}-\epsilon_{ij}).
\]

在每条跨度都落入它所用的标量区间时，原目标函数满足

\[
F(g)\geq C+b'^Ty+y^TAy,\qquad y=g-g_0.
\]

证书包含精确有理分解 `A=L D L^T`，其中 `L` 为单位下三角矩阵，`D`
的每项严格为正；还包含解 `z`，核查 `A z=b'`。于是

\[
F(g)\geq C-\tfrac14 b'^Tz
 +\sum_kD_k\left(\sum_i L_{ik}(y_i+z_i/2)\right)^2
\geq C-\tfrac14 b'^Tz.
\]

这是成组的非负平方分解，而非分别取 39 个核函数的最小值。它保留了
各跨度来自同一组间距的耦合关系。

## 3. 现有精确证据

`analytic_gram_minorant.json` 给出 69 个相位格室的具体证据。格室由
正整数间距模式 `n` 确定；每个有权跨度要求

\[
\left|\sum_{r=i}^{j-1}g_r-\sum_{r=i}^{j-1}n_r\right|\leq21/100,
\qquad g_r\geq17/20.
\]

69 个格室是从历史探索样本中的低目标点选出的，**不是全域枚举**。
结果为：

- 2,691 个有理标量二次下界，1,150,294 个精确端点检查；
- 69 组 `9 x 9` 精确 Gram/LDL 分解及线性方程核查；
- 69/69 的有理整体下界达到 `433/50000`；
- 最弱整体下界约 `0.008664844248090824`；
- 最大加权标量误差损失约 `9.0204e-8`。

生成器 `analytic_gram_minorant.py` 使用 NumPy/SciPy 仅继承探索数据；
端点、消元、LDL 与最终比较使用 `fractions.Fraction`。独立重放器
`analytic_gram_replay.py` 只用标准库，直接解析冻结上游的 PT 字，不导入
生成器、凸包程序、线性求解器或任何曲率样本；它重建切线误差项、检查
各子区间无缝覆盖、二次端点、Gram 恒等式和最终有理下界。

重放命令：

```text
python -B -X utf8 research-20261016-w10-unconditional/analytic_gram_replay.py
```

## 4. 为什么仍不能消去全域前提

根任务的 `basin-partition-probe.json` 检查了旧分区的全部 191,557 个节点。
没有任何数值子树整体包含于上述 `21/100` 格室；因此不能据此声称已经
删除旧证书的任何数值叶。

扩大到 `49/100` 而保持相同二次系数，只有 33/69 格室达到目标，最弱
下界降至约 `0.00857832118`。长跨度在相位峰附近出现真实的二次越界，
必须降低该项曲率或再分区；单纯换一个包装无法修复。

针对该明确的越界原因，`analytic_gram_wide_adaptive.json` 在每项中取

\[
\alpha\leq\min_{x\text{ 为折点},\,x\ne t_0}
 \frac{V(x)-\ell(x)+10^{-7}}{(x-t_0)^2},
\]

再向下量化为有理数并重新进行全部端点和 LDL 检查。宽格室于是也有
69/69 组达到原目标，最弱整体下界约 `0.00866232418945405`，最大加权
误差约 `3.5991e-7`。这降低的是证书的辅助曲率，没有改变候选压力或
目标常数。宽格室也尚未覆盖全域。

宽格室重放命令为：

```text
python -B -X utf8 research-20261016-w10-unconditional/analytic_gram_replay.py analytic_gram_wide_adaptive.json --output analytic_gram_wide_adaptive_replay.json
```

`analytic_memory_probe.json` 另给出一个有限记忆方案的明确数值障碍：丢掉
唯一的跨度 9 项后，存在目标值约 `0.00859183404` 的合法间距，低于
破当前纪录所需的约 `0.00862965`。因此不能直接截去远程相互作用。

尚缺的关键数学步骤是：证明所有低于目标的候选反例必然落入一个已证
格室，或建立带格室分类的新全域分区；随后需把上述通用平方和检查器
及具体有限数据接入 Lean。未完成这些步骤前，本目录不提供无条件的新
零点比例，也不应作为网站提交的最终证明。

## 5. 同五个模式的精确边界阻隔

`analytic_boundary_probe.json` 限定在宽域 Gram 下界最低的五个模式，对
39 条有权边的两侧共 390 个边界做一次确定性约束极小化。362 个浮点
可行任务的线性残差均不超过 `1e-8`，找到的原函数 `F` 最小值约
`0.011679425376`。没有找到反例并不证明相位集中。

进一步，`analytic_boundary_gram.json` 不再依赖浮点极小化，而在同五个
模式的 390 个边界上检查精确有理 Gram 阻隔。若 `A z=b'`、`A h=v`，
并且边界写成 `v^T y=d`，则令 `k=d+v^Tz/2`，由

\[
(y+z/2)^TA(y+z/2)-\frac{k^2}{v^Th}
=\left(y+z/2-\frac{k h}{v^Th}\right)^TA
 \left(y+z/2-\frac{k h}{v^Th}\right)\geq0
\]

得到边界下界

\[
F(g)\geq C-\tfrac14 b'^Tz+\frac{(d+v^Tz/2)^2}{v^TA^{-1}v}.
\]

390/390 个有理边界下界都超过 `433/50000`，最弱约
`0.00912161213594`。生成器核查 `A h=v`、分母正性、约束极小点和对应
二次型的精确值。

这个阻隔只对**格室内且位于该边界**的点适用。二次下界继承的 PT
有效域有限，因此不能把它外推到格室外；也不能据此推断全域低子水平
集连通，或排除另一低值连通分支。
