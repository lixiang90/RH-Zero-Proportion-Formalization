# 消去 W10 前提的后续研究

**尚未证明新的无条件零点比例；网站提交状态仍为 false。**

本轮保持十点权重、压力、目标 `433/50000` 及候选分数完全不变，研究用可复用的
成组二次证书取代大量逐叶切线见证。详细数学内容见
[analytic_gram_note.md](analytic_gram_note.md)。

已完成的核验范围分别是：

- [普通 Lean 模块汇总](../research-unconditional-20261016/verified-module-summary.json)：
  通用凸二次包络、上游 PVI 切线桥、对角配方下界及 69 个具体多项式下界均通过。
  `BasinPolynomials` 只证明给定多项式的下界，没有自行证明原核函数的区域包含。
- [窄域精确重放](analytic_gram_replay.json)与
  [宽域精确重放](analytic_gram_wide_adaptive_replay.json)：每组 69 个格室、2,691 个标量
  二次下界，逐项重建冻结 PT 支持，检查有理端点和 Gram/LDL 恒等式。宽格室最弱
  整体下界约为 `0.00866232418945405`，高于 `0.00866`。这是独立整数/有理证据，
  尚未逐实例转成 Lean 证明。
- [混合分区试验](hybrid-pilot-summary.json)：可把新的 Gram 叶纳入保留全部补域的
  分区，但未决区域仍存在，也未显示全局压缩收益。强制雕刻格室反而增加了部分切割。
- 固定 90 字段的几何解释器已证明与原操作相等；同一真实 32 叶的完整核检查
  从 `16.691` 秒降至 `11.770` 秒。真实 128 叶也通过。
  按步物化 dual 和缓存 slope 的两个试验更慢，没有采用。

原树的全部 191,557 个节点已作包含检查；不论格室半径取 `21/100` 还是
`49/100`，均没有可直接由这些格室替换的数值子树。不能据此删去原树。

因此仍需证明所有可能的低值反例都落入已证区域，或构造没有未决补域的新分区，
并把每个具体标量证书及完整覆盖接入 Lean。随后才有资格组装不超过网站源码上限的
无条件单文件并进行固定陈述比较和双内核重放。此前完成的完整有限整数审计不能
替代这些步骤。

复现命令见详细数学说明。旧 W10 的冻结输入、证明及提交草稿没有被本轮试验覆盖。
