# 固定点对全原域 pressure-affine 预算的独立审查

日期：2026-10-17。结论：**正确；固定点重放通过，且证明整个指定预算接口的统一 cap**。这不是连续 floor 的反例，也不是极小点限定预算、coupled support 或整体取整方法的 no-go。

本包未修改旧冻结包或治理计数；没有新点、新锚点、优化器、核/超越函数评价、树扫描或 Lean 编译。仅使用标准库 Fraction 重放同一个预声明原二进制有理点及已经保存的 all-2 整数配置 cap。

## 1. 被排除接口的精确量词

固定实际 24-mode 核、当前 NewLedger、`s=123/128` 和 `delta=5/128`。记

`O={g in R^9 : all g_r>=s}`，`I={h in Z^9 : all h_r>=1}`，

`P(g)=sum b_r*g_r`，`B=sum b_r`，

`Phi(g)=sum_(i<j) a_ij*(w(span_ij)-hatw(span_ij+(j-i)*delta))`。

只考察满足以下条件的实数常数 `alpha,beta,L`：

1. `alpha>=0`，`beta` 任意实数；
2. `L<=F(h)` 对每个 `h in I` 成立，包括允许选择最佳统一整数 floor；
3. `Phi(g)>=-alpha*P(g)-beta` 对每个 `g in O` 成立。

共同取整平均 `A(g)` 满足精确恒等式 `F(g)=A(g)-delta*B+Phi(g)`，且 `A(g)>=L`。因实际边系数非负、`w=k^2>=0`，有 `P(g)<=F(g)`。故此接口产生的连续 floor 是

`C=(L-delta*B-beta)/(1+alpha)`。

这里没有使用所求 floor 来证明预算，也没有从全局极小点的上向比较反推缺陷下界。

## 2. 单点给整个接口封顶

取被冻结的原有点 `g* in O`，并取整数配置 `q*=all 2 in I`。区间算术给出

`F(q*)<=Uq`，`Phi(g*)<=Uphi`，`P*=P(g*)`，

并定义 `T=Uq-delta*B+Uphi`。任意合法预算在 `g*` 上都须满足

`beta>=-Phi(g*)-alpha*P*`。

因此对于所有 `alpha>=0`、任意实数 `beta` 及任意合法统一整数 floor `L`，严格有

`C <= (Uq-delta*B+Uphi+alpha*P*)/(1+alpha)`

`  = (T+alpha*P*)/(1+alpha) <= max(T,P*)`。

本次精确比较得到 `P*<T`，所以 **`C<=T` 对整个指定接口成立**，无需固定某个 alpha、beta 或采用 `L_adj`。q* 仅用于封顶统一整数常数；不需要它属于 g* 的实际取整支持。

若预算仅对全局极小点、KKT 点、某个 sublevel 或额外条件下的剩余域成立，则必须先证明 g* 属于那个域，不能直接应用本 no-go。若整数 bound 依赖 g 或实际取整支持，上述统一 L 的封顶也不适用。其他函数型压力付款、其他 ledger、其他核、其他取整和其他计数办法均不在本结论中。

## 3. 固定点身份与独立算术

连续点只读取已 pin 的 `research-goal-20261017-ternary-coboundary/support-audit.json` 中 `zeroV_minimum_sample_exact_binary_float_gaps` 九个有理字符串，并核对已冻结身份审查清单及身份 receipt。没有十进制重舍入或点替换。该 tuple 中看似镜像的两项存在 1 ulp 差别，独立实现保留这个差别，不强行对称化。

`replay.py` 不导入或执行生产者脚本。它直接用 gap 切片求跨度，将 41 条正边按 **30 个精确跨度**合并；再按幂的符号选择系数区间端点，直接计算 0..23 阶 Taylor 幂和，而非生产者逐边 Horner。偏移为负时，奇数幂正确交换系数上下端点。余项为

`(44/7)^24 * abs(offset)^24 / 24!`，

来自既有实际 24 阶导数界。插值独立按 `t=span+(j-i)*5/128` 的精确 floor/frac 分配非负权重，并先合并各整数端点的总权重。没有独立对各边取整，也没有丢失共同取整所确定的精确平均公式。

全部 41 条生产边的中心、偏移、余项、插值端点、插值权重、w 区间、插值区间与 defect 区间均逐分数一致；总 Phi/F 区间也逐分数一致。all-2 整数 cap 另外直接从相同旧表的零阶系数、按距离聚合全部边权独立重算，等于此前固定 receipt 的端点。

还将参数 JSON 的 45 条边和 9 项压力逐项与 `NewLedger.lean` 字面系数核对相等。固定 H、R 与比例公式分别绑定到 `WindowEnergyBound.H24_ge` 及 `WindowRecordLowerFloor.kappa_eq/improvement` 的源码接口；本次没有重新编译这些既有材料或新建 Lean 定理。

## 4. 复核结果与目标幅度

独立结果（以下小数仅展示，判定全部使用精确有理数）：

- `P*=0.006207494896760311`；
- `Phi(g*)` 约为 `-0.0022632349548898072`；
- `T=0.007388741326026388`；
- `F(g*)` 约为 `0.008847438760183953`，其严格下端高于三个目标。

固定当前形式化解析下界

`H0=6720963398090236473924/10^22`，`B=11055671/2500000000`，

以及源码中已记录的有理纪录 R，置 `K=R+1/100000`。当前计数接口的系数是 `(H0-B)/(1-c)`，其等于 K 的阈值为

`c_req=1-(H0-B)/K`

`=5349002676301735733991141164305905087919557/608906172631303644195215758819391372800000000`

约为 `0.008784609052634106`。要由这个固定 H0/B 接口严格超过 K，需要 c 严格高于该阈值。

`rho=(H0-B)/(1-T) ≈ 0.6726440644054023 < R < K`。

完整精确有理数保存在 `receipt.json.fixed_H_counting_coefficient_cap` 和 `cap-comparison.json.fixed_H_B_counting_coefficient_cap`；没有用 source float 或显示小数参与任何证明比较。后者由独立纯 Fraction 后处理将根代理冻结的 `family-cap.json` 中 T、rho、`R-rho`、`K-rho` 四个有理字段逐项核对，全部相等。根代理后处理脚本本次只读取并 pin，没有导入或执行。

这是**这个固定接口可证明的下界系数的 cap**，绝不是实际 zeta 零点比例的上界。更精确的 H 或其他实际函数/计数接口不在该 cap 的量词范围内。

点自身实际能量高于目标，所以它不反驳连续 floor，也不能因其历史名称含 best/minimum 就假设它是真正全局极小点。本结果只证明这类全原域 uniform scalar pressure-affine 缺陷预算无论怎样选 alpha、beta 或统一整数 L，都达不到所列幅度。没有产生新连续 floor、完整形式化证明或新的无条件纪录。
