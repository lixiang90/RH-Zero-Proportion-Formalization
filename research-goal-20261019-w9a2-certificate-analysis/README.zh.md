## 本轮新的非平凡机会：低态图无环

最低七个叶的 floor 余量只在约 `1.26e-13` 至 `1.38e-13`。第八叶却有
`1.2139059352452098e-9` 的余量。直接用最弱单窗浪费了这个差别。

取新阈值

```
tau = 893029151313702349 / 10^20
```

即把原 `cN` 加 `121390593524`。第八叶是最大可取整数提升的瓶颈；扣款后仍有整数余量
`174811036164000000`。只有排序前七个数值叶不能直接达到 tau。

为每个低态保留正、反两个朝向，得到 14 个顶点。顶点编号为
`2 * 从0起的叶排名 + 是否反射`。前窗使用点 0 至 8，后窗使用点 1 至 9，
共享七个间隙。反射将 span `(i,j)` 映射到 `(8-j,8-i)`。

196 个“前态 × 后态 × 四朝向”中，189 项均有直接共享 span 的闭区间分离矛盾。
其余七条有向边为：

```
1 -> 10   3 -> 10   4 -> 5   5 -> 8
9 -> 4    11 -> 0   11 -> 2
```

图无环，最长路径为 `9 -> 4 -> 5 -> 8`：**4 个顶点、3 条边**。
因此若完成全域定位与滑窗计数，连续五个窗至少一个可按 tau 支付；这是一种相邻窗约束，
超出了单窗常数微调。`geometry-audit.json` 给出所有排除的直接矛盾、每条保留边的十点整数可行 witness、拓扑序及逐点秩。
保留边只证明两个外包状态盒可相容，不代表实际能量达到两个最弱值。

若上述全域数学与 Lean 门槛完成，可导出的保守平均 floor 为

```
c* = 4465145271006137649 / 500000000000000000000
```

把它代入原计数合同，候选比例为

```
3337881639516708570682858853672166187793 /
4955348547289938623510000000000000000000
= 67.359169746842195661824153817... %
```

较本次网站纪录约高 `1.650089699e-8` 个百分点。**这只是有明确有限证据的待形式化候选，不能作为已证明纪录提交。**

外域不必提高每条孤立 WZ guard：在实际分离域 `g_i >= 17/20`，true-WZ 分支已有至少原 floor 的平方核能量，另可加八个间隙的压力；tail 分支由单个压力支付原 floor，另有其他七个压力。精确有理余量见 `source-comparison.json`，均远大所需 tau 提升。仍须将该观察写成新的全域 Lean 定位/反射定理，并连接数值叶、图排除、五窗计数及实际 ζ 根计数合同。

## 文件格式与复现

状态是 73 个整数：`L0,U0,...,L7,U7`，接着按
`PR=[(i,j) for i in range(9) for j in range(i+2,9)]`
排列全部 `Aij,Bij`，末尾为 0。所有 gap/span 闭区间单位为 `1/32768`。
`geometry_audit.py` 直接读已排序的有限整数叶；其 DBM 检查只做十点差分约束 Floyd–Warshall。
可行 witness 是闭包的 `d[0][i]`，逐条代回两窗全部区间检查。

`packing_parser_w9a2.py`、`record_math_w9a2.py` 和 `replay_w9a2.py` 从已有 baseline 工具定向适配；改动源 pin、floor、压缩数目、根定理格式与可选 noncomputable 标记。
后续编辑仅澄清脚本注释，不改变已运行函数的语义。
重放脚本拒绝覆盖既有 `baseline-replay.json`，复现请在新的输出目录运行。
`files.json` 固定本目录的交付文件及依赖源 SHA256。
