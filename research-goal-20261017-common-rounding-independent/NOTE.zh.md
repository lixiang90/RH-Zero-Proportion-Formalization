# 共同随机平移取整：独立静态审查

日期：2026-10-17。结论：**correct**。这是原分离正交域上全局极小点的一个必要条件；没有产生新的全域 floor 或无条件零点比例。主代理宏观计数保持 2，本审查不改计数。

审查只读取源码并作纸面代数推导；没有调用优化器、核数值、覆盖树扫描或 Lean 编译，没有建立 Lean 模块。下面的“平均”全部是有限凸组合。

## 1. 命题与有限构造

令 `s=123/128`，`eps=1-s=5/128`，`g_r>=s`（`r=0,...,8`），`p_0=0`、`p_i=sum_(r<i) g_r`，`x_i=p_i-i*s`（`i=0,...,9`）。则 `x_0=0`，且

`x_(i+1)-x_i=g_i-s>=0`。

对 `0<=u<1` 定义整数点 `q_i(u)=i+floor(x_i+u)`。同一 `u` 用于所有点，不能分别独立取整。由于 floor 单调，

`q_(i+1)(u)-q_i(u)=1+floor(x_(i+1)+u)-floor(x_i+u)>=1>=s`。

同时 `q_0(u)=floor(u)=0`。令 `h_r(u)=q_(r+1)(u)-q_r(u)`，则 `h(u)` 属于原来的分离正交域，且其部分和恰好为 `q_i(u)`，所以用 `F(h(u))` 比较时没有位置原点误差。取整配置不必满足原点 `g` 的反射定向、父单元、pressure box 或低能量条件；完整正交域中的可行性已经足够。

写 `x_i=k_i+f_i`，其中 `k_i=floor(x_i)`、`0<=f_i<1`。每个 `f_i>0` 只在 `u=1-f_i` 跳跃。取集合

`T={0,1} union {1-f_i : 1<=i<=9, f_i>0}`，

并将不同元素排序为 `0=t_0<...<t_m=1`。因为 `x_0=0` 没有内部跳跃，**`m<=10`**。在每个半开区间 `[t_l,t_(l+1))` 上，整个点向量 `q(u)` 恒定。选左端点 `u_l=t_l`，权重 `theta_l=t_(l+1)-t_l`；于是 `theta_l>0`、`sum theta_l=1`。这给出至多十个实际可行配置的有限凸组合，故题设“至多十一”也正确；需要固定 `Fin 11` 时可用零权重补齐。

取整在阈值处右连续，故左端点选择包含正确的跳后值。`f_i=0` 的坐标整段不跳；多个相同阈值同时跳，不插入虚构的中间配置；`u=1` 不在任何配置中。所有 `g_r=s`、整数 `x_i`、整数边跨度等边界均包括在此构造内。

## 2. 有限两点分布与精确能量恒等式

记 `E H=sum_l theta_l H(u_l)`。有限区间长度给出

`E floor(x_i+u)=k_i+f_i=x_i`。

对任意 `i<j`，令 `k=j-i`、`d=x_j-x_i>=0`、`n=floor(d)`、`alpha=d-n`。由基本 floor 恒等式，

`floor(x_j+u)-floor(x_i+u) in {n,n+1}`。

当 `alpha=0` 时差恒为 `n`，包括全部阈值端点。当 `alpha>0` 时，因平均差为 `d=n+alpha`，高值 `n+1` 的总权重必为 `alpha`，低值总权重为 `1-alpha`。这一步使用共同 `u` 所给出的两点支持；不同边之间可以高度相关，求有限边和的平均不需要任何独立性。

为 `t>=0` 定义整数采样的线性插值

`hatw(t)=(1-frac(t))*w(floor(t))+frac(t)*w(floor(t)+1)`。

因为 `q_j-q_i=k+n` 或 `k+n+1`，且 `p_j-p_i=k*s+d`，故严格有

`E w(q_j-q_i)=hatw(k+d)=hatw((p_j-p_i)+k*eps)`。

同理 `E h_r=g_r+eps`。因此对题设能量（任意有限实值 `w` 即可）有

`E F(h)=sum_r b_r*g_r + eps*B + sum_(i<j) a_ij*hatw((p_j-p_i)+(j-i)*eps)`，

其中 `B=sum_r b_r`。连续性和 `a,b>=0` 并不是这个有限恒等式所需的额外前提；它们在实际模型的连续性、非负性和极小点存在性中有用。

如果 `g` 是**完整原正交域**上的全局极小点，则每个 `F(g)<=F(h(u_l))`，乘非负权重相加并使用 `sum theta_l=1` 得

`sum_(i<j) a_ij*(w(p_j-p_i)-hatw((p_j-p_i)+(j-i)*5/128)) <= 5*B/128`。

所以题设公式没有压力符号或位移符号错误。注意插值参数是**原跨度加上** `(j-i)*5/128`；不是原跨度本身，也不是减号。

## 3. 实际源码对应与 scope

题设要求的 `StructuralGoal20261016/WindowMinimizer.lean` 不存在；对应 API 是 `WindowMinimizerCover.lean`。

- `WindowMinimizerCover.lean:15-17` 的 `Relevant` 明确包含完整正交域全局比较；取整配置无需定向。`:60` 的 `RelevantBelow` 额外携带 `F<c`，`:63` 的 `global_floor_of_checked_below` 可以接收只保持这种极小点的 contraction。
- `NewLedger.lean` 的 `pressure_eq` 给出 `B=11055671/2500000000`；本必要条件的实际右端因而精确为 `11055671/64000000000`。这是有理代数代入，不是核数值评价。

该结论不适用于任意 KKT 点、局部极小点或任意 `F<c` 点。一个完全显式的通用反例是：只令 `a_01=1`，其余边系数与全部压力系数为零；取 `g_0=3/2`，其余 gap 取 `s`，并令

`w(t)=(1+(t-3/2)^2-20*(t-3/2)^4)^2`。

此时 `w(3/2)=1` 是严格局部极小值，`w(1)=w(2)=0`；故该 `g` 是可行局部极小点并满足 KKT，也属于 sublevel `F<2`。共同取整的首 gap 只取 `1,2`，平均能量为零，公式左端为 `1`、右端为 `0`，结论失败。这个例子说明逻辑前提不能削弱；它不是对实际 24-mode 核的数值断言。

## 4. 与旧整数 gap 平移的关系

`cover_global_cut_allmoves.py:16-28` 产生整数 `delta`：单坐标 `+/-1,+/-2`、两坐标 `+1,-1`，以及整数 pattern 减整数 rounded center。`:125` 正确声明只保持原域低能量全局极小点。所有旧比较 `g -> g+delta` 保持每个 gap 的小数部分。

这里 `h_r(u)` 全是整数，通常 `h_r(u)-g_r` 不是整数。因此它没有被该旧整数平移家族字面包含，也不能仅由所有整数平移比较形式推出。后一点有显式例子：仍取仅 `a_01=1`、`b=0`、`g_0=3/2`，令 `w(t)=sin(pi*t)^2`。每个可行整数 gap 平移保持能量 `1`，所以连“所有整数 delta”的比较都成立；共同取整配置的能量却全为 `0`，新必要条件排除此点。这只是非冗余性的通用例子，尚未证明对当前实际核有全域收益。

令 `c_goal` 是当前实际 ledger 经既有计数桥所要求、足以严格超过 `R+1/100000` 的精确能量 floor，并令

同时交付 `U` 所需的实际核 floor 证据与整个原域的量化节省；若还使用 KKT 或其他已证全局必要条件，必须逐项保留在 gate 的前件中。一个可行 `g` 若满足 gate 的全部前件却不属于 `U`，就直接推翻该分类；只验证有限样点、单个单元或抽象插值引理不能通过此关。允许放宽的早期检查是证明一个明确定量、覆盖原根域的分类缩减，但必须报告尚未处理的补域。
