# 固定 prefix/suffix 组合：可核查的非线性机会关

只静态审查固定组合 `W=(delete0+delete9)/2`，不解新的优化问题。
此处允许改进联合实际 floor，故不受旧包仅复用 `c9*sum lambda`
的线性对偶上界排除。也不受已保存另一支撑 `{0,1}` 的零间隔结论
排除。

对九个十点间隔，定义

`E_L(g)=F9(g0,...,g7)`，`E_R(g)=F9(g1,...,g8)`。

新实际能量恰为 `(E_L+E_R)/2`。两份窗口共享七个间隔。逐边取
平均后，秩跨度 1 至 8 的配对质量与原九点 ledger 相同，跨度 9
质量为零，所以旧容量均不超过 2。总压力仍是
`B9=54711/12500000=0.00437688`。这些有限系数等式已在
`audit_static.py` 中用冻结 endpoint 两列和原源常数复核，没有
优化或核评价。

## 固定目标与完整数学逻辑

固定机会关取 `c=8611/1000000=0.008611`。冻结窗下界 `H` 给出
条件比例约 **67.3591829810618%**，超过 `K=R+1/100000`。
已有同旧核的 `123/128` 短对支付为 `0.00866`，足够支付该 `c`。
目标所需的最小 floor 严格大于约 `0.008610231572178169`。

若反例 `(E_L+E_R)/2<c` 存在，旧全域定理 `E_L,E_R>=c9`
强迫两者都严格小于

`t=2*c-c9=862661474086124519/10^20`

即约 `0.00862661474086124519`。因此一个具体充分命题是：

> 对所有 `g_r>=123/128`，不能同时有
> `F9(g0,...,g7)<t` 与 `F9(g1,...,g8)<t`。

若证明该命题，便得到所需的完整 separated 十点 floor。它是新全域
非线性兼容性命题；**当前未证明它成立**。

可用有限有理集合 `E` 覆盖所有 `h_r>=s` 且 `F9(h)<t` 的八间隔
配置。对每个两个例外 cell，在同一个十点位置系统中放入两份 cell
跨度约束与 `g_r>=s`。如果每对约束均由精确负循环证明不可行，
上面的全域命题成立。等价地可在旧九点差分约束矩阵闭包后，把端点
消去，比较两个共享七间隔状态的投影。只做几何不兼容检验时，投影
可取外包；必须覆盖全部例外及其反射，不能只测旧极小点样本。

## 现有证书的可复用接口与尚缺的工具

Core 中已经泛化 floor 的低层接口是：

- 第 9282 行 `PCell.Pg (cN Q) bs TS`；
- 第 9398 行 `PCell.root_cover {cN}`；
- 第 10076 行 `PCell.mcheckGX ... (TS) (cN) cell FS P S Cp Cm`；
- 第 10091 行 `mcheckGX_sound`，其中 `cN` 也是显式参数。

`mcheckGX` 的主要整数不等式中，新 `cN` 只出现在
`335544320000000000*cN` 一项；核 lower pyramid、导数/切线证书、
已存的 FS 与 flow 不必因目标改变而重算。可以只读旧 leaf 的见证，
得到这条见证可证的最大 floor；不足以证明 `t` 的 cell 留作例外，
其余 cell 用同一见证证明新阈值。

但是目前的高层 API **没有**可直接传入新 floor 的旧遍历器。
`PC9QB6M.Covered`（10575附近）、`mcheckP`、`mleafP`、`walk`
及 `PC9QB6MData.cert` 均绑定旧 `cN`。已有数据是 Core 内的
`WLr_k` 压缩整数、`WLr`/`WDr` 分派、`COV`、`SMAX` 和 `RC`，
不是已导出的带几何 leaf 列表。`rdw` 在 11018 行，`node`、
`walkC`、`walk` 在 11019–11026 行描述流的正式解释器。

因此下一步若获准，只能先实现并独立回放一个**保持旧偏移与分支**的
只读检查器。新阈值失败时，原 `mleafP` 返回零，不能直接把原
`walk` 换常数后继续走；必须先完整解码见证以保留原消耗位数。
然后才可能输出完整例外 antichain 和相应覆盖命题。本轮没有实现
这个检查器，也没有解码任何 leaf 或枚举 cell 对。

反射必须显式处理：旧 `Pg` 的第二分支是 `g7<g0`，不是能量下界。
`leafStep` 的 reflection 叶仅在有序半域中排除几何。应先在
`h0<=h7` 的半域提取例外，再把反射 cell 加入全域例外集合。
不能把旧 reflection 成功误当作任意提高阈值后仍有能量付款。

## 完整性前置关：原根森林仍能定位新 separated 低能配置

只筛旧 numerical leaves 而遗漏根外区间是不充分的。原 `COV` 的
true unary 区间给出一条相邻项本身至少 `c9`；在固定 separated
域，另有完整压力至少 `s*B9`，所以这些区间实际给出

`F9 >= c9+s*B9 = 0.012801293384138756 > t`。

原 `SMAX` 的八个尾部压力付款加上其他间隔的基线为

`b_r*SMAX_r/32768+s*(B9-b_r)`。

这八项的最小值为 `39139819/3200000000=0.0122311934375>t`。
`s>1/2` 直接排除原根覆盖的最小间隔分支。故旧 `COV`/`RC`
定位逻辑可以在 separated 低于 `t` 的配置上复用，但必须写出上述
额外压力的证明；不能直接复用全非负 `root_cover` 的旧 `hS/hcov`
断言为更高阈值断言。所有八项检查已在本包精确回放。
