## 1. 精确逻辑与作用域

置 `delta=5/128`，`s=123/128`，`B=sum b_r`，并记共同取整配置的有限平均能量为 `A(g)`。此前已审查的精确恒等式是

`F(g)=A(g)-delta*B+Phi(g)`，

其中 `Phi(g)=sum_(i<j) a_ij*(w(span_ij)-hatw(span_ij+(j-i)*delta))`。这个恒等式对每个原域可行 `g` 都成立，不需要全局极小性。

考虑仅用下列两个独立常数来转移 floor 的规则：

- `L<=F(q)` 对全部整数 gap 配置 `q_r>=1` 成立；
- `m<=Phi(g)` 对全部原域配置 `g_r>=s` 成立。

那么该规则给出的 floor 是 `L-delta*B+m`。对两个预声明可行点 `q*=all 2` 和 `g*=all 21/20`，必有

`L-delta*B+m <= F(q*)-delta*B+Phi(g*)`。

所以只要该右端的严格 outward **上界**小于目标 `c`，就可否定所有仅靠这两个全域常数达到 `c` 的规则。此推理没有假设试点是极小点，也没有假设期望中的全域 floor；作为 no-go 条件是正确的。

作用域不能扩大：若 `m` 只在全局极小点、KKT 集、`F<c` 集或其他已排除后剩余域上有效，就不能代入未证明属于该域的 `g*`。若整数 lower bound 依赖 `g` 或它实际产生的有限取整支持，就不能无条件拿 `q*` 给它封顶。点依赖的耦合界、其他取整规则以及加入其他实质信息的证明均未被此检验否定。

尤其 `q*=all 2` **不是** `g*=all 21/20` 的共同取整配置：后者 `x_i=57*i/640`，`x_9=513/640<1`，故取整总跨度只能是 `9` 或 `10`，而前者总跨度是 `18`。这不妨碍给全整数域常数 `L` 封顶，但计算量 `F(q*)-delta*B+Phi(g*)` 不能冒充 `F(g*)` 或 `g*` 的平均取整能量。

潜在循环须避免：全局极小性只给 `F(g)<=A(g)`，即 `Phi(g)<=delta*B`，这是上界，不能倒用为缺陷下界；也不能先使用所求实际 floor 来证明 `m` 或 integer floor 的有效性。

## 2. 固定端点和 outward 方向

对距离 `d=j-i`（`1<=d<=9`），两个点的跨度分别是 `2*d` 和 `z_d=21*d/20=d+d/20`。因为 `0<d/20<1/2`，Taylor 中心严格为整数 `d`，偏移为正的 `d/20`；所有中心都在既有 `1..32` 表内，没有 tie。

取整插值参数严格为

`t_d=z_d+d*delta=697*d/640=d+57*d/640`。

因为 `0<57*d/640<1`，正确整数端点就是 `d,d+1`，上端点最大为 `10`。下端权重为 `1-57*d/640`，上端权重为 `57*d/640`，均非负。整数点 `q*` 的跨度 `2*d` 最大为 `18`，只读零阶系数即可。

已存表给出归一化 Taylor 系数区间 `c_(d,r)`（`r=0,...,23`）；已证明的实际导数界是 `|w^(24)(x)|<=(44/7)^24`。因此固定点的余项付款是

`R_d=(44/7)^24*(d/20)^24/24!`。

本独立脚本按距离先合并边权，再直接计算各项的幂和，并在两端减/加 `R_d`；生产者逐边采用 Horner。因为偏移为正，两种有理区间运算给出完全相同的精确端点。对差 `w-hatw`，下界使用 `w_lower-hatw_upper`，上界使用 `w_upper-hatw_lower`；全部非负边权保持端点方向。最终 no-go 试量的上端使用 `Fq_upper-delta*B+Phi_upper`，方向正确。

本包只重放冻结表的有理区间算术及现有解析余项接口，不重生成表、不重新编译旧表的解析消费者，也没有新增 Lean 定理。

## 3. 独立重放结果

`replay.py` 不导入或执行生产者 `check.py`。它 pin 生产脚本、冻结 receipt、参数 JSON、整数 jets 表以及读取的数学源文件；独立核对参数 JSON 的 45 条边与 9 项压力，逐项等于 `NewLedger.lean` 的字面数据。

- `F(q*)` 约为 `0.009824721140291195`；
