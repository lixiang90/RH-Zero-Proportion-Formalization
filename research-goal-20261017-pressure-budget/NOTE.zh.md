# 全原域统一压力仿射舍入预算的严格障碍

有理检查；不重开旧试验，不换点、核、精度或阶数，不运行优化器、
覆盖搜索或 Lean。只评价已有整数 jet 的 Taylor 多项式与已证的
全局余项，没有新整数锚或新的超越函数数据。

## 被检验的完整证明接口

原域 g_r>=s=123/128，压力 P(g)=sum b_r*g_r>0，B=sum b。
公共偏移的整数取整给精确恒等式

    F(g) = avg F(q) - delta*B + Phi(g),   delta=5/128.

设 L 是整个正整数 gap 域上有效的统一能量下界，并试图在整个原域
证明 Phi(g)>=-alpha*P(g)-beta，其中 alpha>=0，beta 是任意实数。
由于 P<=F，接口产生的连续域下界为

    C = (L-delta*B-beta)/(1+alpha).

下面排除的是这个**全原域、统一标量常数、压力仿射**接口，包含
所有 alpha>=0、任意 beta，以及任何可能更强的有效统一整数 L。
不只是排除上一轮算出的 L_adj。

## 全参数族的上限

预算在 g* 处强制 beta>=-Phi(g*)-alpha*P(g*)。故

    C <= (Uq-delta*B+Phi_upper(g*)+alpha*P(g*))/(1+alpha)
       = (T+alpha*P(g*))/(1+alpha)
      <= max(T,P(g*)) = T。

最后一步使用 alpha>=0 和本点 P<T。所有比较均由精确分数完成。
所以无须扫描 alpha、beta 或改进整数 floor，就能排除本接口得到
.0088、.00884，甚至当前正式 H/B 与 R+1/100000 对应的最低
c≈.008784609052634106。

若固定当前已形式化窗下界 H、压力 B，并用 `(H-B)/(1-C)` 计数，
本接口能产出的比例下界系数至多约 **67.2644064405%**，低于网站
当前纪录。这是该证明接口的能力上限，**不是 ζ 零点真实比例的
上界**，也不是其他数学方法的能力上限。`family-cap.json` 保存
这个纯算术后处理的精确分数；它不增加任何核点评价。
