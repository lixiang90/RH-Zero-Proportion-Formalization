# 压缩运行格式与二阶检验（2026-10-16）

本批是覆盖证书的无损存储改进，未改变数学搜索顺序，也未完成全域覆盖或证明新的零点比例。

`cover_compact_codec.py` 将每个 OBBT 坐标界只记录所选跨度、符号、非负能量乘子、标量支持点的权重和两棵有向流森林。原 cell 上下界、支持线系数、混合截距和九个 gap 系数、两个流的散度及每条边流量、边成本、坐标有理界、向外舍入和闭包均在重放时恢复。Newton 每轮共享一份 41 项仿射数据，各方向只记录整数方向和两棵森林。value 和相关方向叶也按相同原则压缩。

每个展开后的原始证明单元必须匹配压缩时保存的规范 JSON SHA256，随后仍交给原来的独立数学 verifier 检查。森林恢复算法只构造候选流，非负性和精确平衡仍须检查。没有把求解器输出、流的最优性或 SHA256 本身当成数学证明。

- 原 500 节点试运行 34,810,164 字节，压缩为 5,676,247 字节 JSON、1,018,795 字节 gzip。所有原始字段逐项恢复，完整独立重放通过：411 个 OBBT 路径、5652 个坐标界、795 个 Newton 步骤、245 个叶、11 个待处理节点。
- 新压缩 runner 从该完整前缀续至 600 节点后，再次完整独立重放通过：487 个 OBBT 路径、6821 个界、849 个 Newton 步骤、294 个叶、13 个待处理节点。
- 稳定的 22,500 节点临时快照从 882,186,203 字节流式压到 147,894,201 字节；转换读取同一个文件句柄并计算来源 SHA256，逐单元处理，不把原始大 JSON 一次性装入内存。该完整前缀随后通过完整独立数学重放（583.27 秒）：15,360 个 OBBT 路径、164,093 个坐标界、3739 个 Newton 路径、17,785 个步骤、3256 个 value 叶、7731 个 stationary 叶、254 个 reflection 叶，以及 19 个待处理节点。没有把转换成功替代数学重放；尚有待处理节点，也没有宣称全域下界。
- 旧 runner 在 22,500 节点保存时遇到 Windows `os.replace` 的访问拒绝而终止；完整 `.partial` 已恢复。新的独立 guarded runner 只增加有界的保存重试，使用压缩格式从 22,500 节点继续。原 runner 与冻结的数学 API 均保留不变。

相关二阶曲率实验用中点 Hessian 的负特征向量选取整数方向，对 `w''` 使用仿射 Taylor 包络和 `w''''` 余项，并对共享九个 gap 的仿射和执行精确整数流最大化。300 个 OBBT 残余 cell 中 251 个中点 Hessian 有负特征值，但没有严格负曲率证书；先做最多八轮 Newton 后，58 个 cell 已被一阶排除，剩余 242 个 cell 中 210 个中点 Hessian 有负特征值，仍无严格负曲率证书。这是负结果；零条成功证书的重放不构成新的数学改进。源码与计数保留，暂不继续此方向的盲目参数试验。

联合能量—梯度在同 300 个 OBBT 残余样本上另得到 7 个新增排除，全部独立重放通过，连同 85 个先行 OBBT 坐标界重检。它们没有使用后续 Newton 步骤，仍只是局部覆盖进展。

所有本批结果均保持 `complete_global_cover=false` 和 `new_zero_proportion_proven=false`。gzip 小于 2 MB 的局部样本归档，不等于满足网站对最终完整 Lean 源码的体积要求。
