# Four real nodes on the SQLite fork

The authorized integration pilot completed exactly4 real nodes and exited
successfully after54.45seconds. It did not start a complete search or resume
the original budget. The original main source, all frozen mathematical
sources, the stopped132000-node JSON and the original baseline database
remain unchanged. Only a fresh SQLite backup was advanced.

The fork copies the original call order: reflection; Gram/direction;
value; OBBT; Gram/direction/value; Newton; Gram/direction/value; leaf or
split. It loads only metadata/runtime/frontier and2540 support records.
It does not load historical accepted/branch/OBBT/Newton collections. The
new epoch binds the fork, store, independent node checker and old sources.
A fresh output folder, exclusive writer marker/OS lock and SQLite
transactions guard the single writer. Every authoritative new witness,
support, counter and frontier update goes through append_node.
