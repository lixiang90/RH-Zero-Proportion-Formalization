# 公共偏移的可行整数取整：全局极小点的新必要条件

本说明给出覆盖整个分离正交锥的必要条件。当前仅有数学推导和静态
接口审查，没有新 Lean 定理、排除证书、全域 floor 或无条件比例。
能否显著减少完整证明负担，仍须量化检验。

使用 `WindowGapEnergy.Fw24` 的实际二十四模核平方 w 与同一
`StructuralW10Followup20261016.NewLedger.W`：

`F(g)=sum_r b_r*g_r+sum_(i<j)a_ij*w(p_j-p_i)`，

`p_0=0`，`p_i=sum_(r<i)g_r`，原域 `g_r>=s=123/128`。
`WindowMinimizerCover.Relevant.2.2` 最小化整个原域。竞争配置无需
满足选择代表时的 `g_0<=g_8` 定向约定。本条件不能直接施加到任意
低能量点、任意 KKT 点或 cell 内的局部极小点。

## 可行配置与有限凸组合

令 `delta=1-s=5/128`，`x_i=p_i-i*s`。x 非降且 x_0=0。
对**同一个** `0<=u<1` 定义

`q_i(u)=i+floor(x_i+u)`。

于是 q_0=0，且
`q_(i+1)-q_i=1+floor(x_(i+1)+u)-floor(x_i+u)>=1>=s`。
原边界 g_i=s 也不影响可行性。每个 u 同时决定所有位置；独立逐边
舍入不能保证跨度来自一个可行配置。

对非整数 x_i，内部切换阈值是 `1-frac(x_i)`。把这些阈值去重，
与 0、1 一起排序为 `0=t_0<...<t_m=1`。因为 x_0=0，m<=10。
每个半开段 `[t_l,t_(l+1))` 上 q 恒定，取段内点 u_l，令
`alpha_l=t_(l+1)-t_l>0`，则 sum alpha=1。这是有限实系数凸组合，
不依赖数值积分。保留重复阈值及零权重时也可使用固定 11 段。

对每个参与分割的 x_i，
`sum_l alpha_l*floor(x_i+u_l)=x_i`。
对 z=p_j-p_i、d=j-i，差 floor 只取
`floor(x_j-x_i)` 和 `floor(x_j-x_i)+1`，整数差时仅取前者。
故 q 跨度只取 `floor(z+d*delta)` 和下一整数，加权均值为 z+d*delta。

定义实际整数采样的线性插值

`hatw(t)=(1-frac(t))*w(floor(t))+frac(t)*w(floor(t)+1)`。

精确得到
`sum_l alpha_l*w(q_j(u_l)-q_i(u_l))=hatw(z+d*delta)`。
这里没有 w 凸性假设，也没有使用 Jensen。这是二点边缘分布恒等式；
所有边仍共享同一组可行配置及权重。

## 全局必要条件

每个间隔的平均为 g_r+delta。记 B=sum b，则平均竞争能量为

`sum b*g+delta*B+sum_(i<j)a_ij*hatw(z_ij+(j-i)*delta)`。

全局极小点的能量不超过每个可行竞争配置。乘 alpha 求和并消去
原压力项，得到统一必要条件

`sum_(i<j)a_ij*(w(z_ij)-hatw(z_ij+(j-i)*5/128)) <= 5*B/128`。

实际新 ledger 的 B=11055671/2500000000，付款是
`11055671/64000000000`。不得代入旧十点十二模核的 B 或 w(n)。
q 不需要留在原 cell、压力根、sublevel 或定向子域；原全局最小性
已经比较整个 Orthant。该推导本身不要求一阶、二阶或自由坐标条件。

## 只需要已有整数中心 1–32

若另有 F(g)<c，正压力和 w>=0 给
`T=c-s*B>sum_r b_r*(g_r-s)>=0`。故正边 (i,j) 上

`z_ij+(j-i)*delta < (j-i)+T/min_(i<=r<j)b_r`。

整数竞争跨度至少 d=j-i，至多为右侧上取整。
`geometry_budget.py` 只读冻结有理参数，以 Fraction 核查全部 41
条正边：c=11/1250 和 c=221/25000 的最大整数索引均为 32。
因此有机会直接复用已经建立的实际整数中心 1–32 的值界；本新
条件没有要求新增核阶数、精度或整数中心。这个索引预算本身不重证
旧实际值定理，也不证明新条件具有足够的排除能力。

## 与旧方法的区别、下一关和停止条件

`cover_global_cut_allmoves.py` 的候选给 gap 加常数整数向量，保留
分数相位。本 q 改变相位，变化量和凸权重依赖当前 g。不能把它当
成 cell 内固定整数 delta，直接调用旧 Taylor 差包消费者。
旧无符号相位范数界的反例不自动否定这个保留实际有符号核基准的
比较；新条件正确也不自动证明盆域分类或解决当前 17 个 frontier。

下一关先独立核对推导和有限凸组合接口，再固定完整范围的收益
检验：注明当前 frontier 或可替代的大祖先、真实父域、只保留原
全局极小点、hatw 的严格上界及每个实际整数值证明。只有量化了
全树证明/源码收益，才开新消费者或覆盖批次。不重复已闭合五叶
单元，不将单个例子、通用 API 或新增模块数当无条件比例进展。

还须先过一个非循环性关卡。记偏差和为 Phi(g)，对任意原域 g 有
恒等式 `F(g)=sum alpha*F(q)-delta*B+Phi(g)`。若另有对全部相关
整数配置的统一下界 L，以及偏差和的全域下界 m，才可推出
`F(g)>=L-delta*B+m`。本必要条件只给极小点的 Phi 上界，不能
把它误当所需的下界。

若已经知道所有整数竞争配置都满足 F(q)>=c，则任意 F(g)<c 的点
本来就满足逐个比较 F(g)<F(q)。这时仅加入本必要式不会排除新的
真实低能量点；要有贡献，须证明有用的全域舍入损失界或展示包含
真实函数付款的大范围证书收益。不能把舍入可行、整数井能量高或
通用引理通过当作新 floor。
